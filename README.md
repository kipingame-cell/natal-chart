# Натальная карта онлайн

Полный расчёт натальной карты в браузере — без сервера и сборки (vanilla HTML/CSS/JS).

- Планеты в знаках и домах, ретроградность
- Дома по Плацидусу, Асцендент, MC, Вертекс, Парс Фортуны
- Аспекты с орбами и конфигурации (Большой тригон, Тау-квадрат, Парус, Бисекстиль, Большой крест)
- Кармические точки: лунные узлы, Селена (Белая Луна), Лилит (Чёрная Луна)
- Астродины (сила/гармония, упрощённая модель), баланс стихий и крестов
- Русскоязычные интерпретации для всех положений

Эфемериды: [Astronomy Engine](https://github.com/cosinekitty/astronomy) (MIT) — файл `public/vendor/astronomy.js` подтягивается из апстрима при деплое (sha1 `716c921ad815df4174828663961fee7ec81906ad`).

Локальный запуск: `node server.js` → http://localhost:3000 (скопируйте `astronomy.js` в `public/vendor/`).

Тесты: `node --test` (сверка эфемерид, домов, Парса Фортуны, аспектов и конфигураций с эталоном).
