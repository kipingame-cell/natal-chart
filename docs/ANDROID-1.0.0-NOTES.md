# Натальная карта для Android 1.0.0

Android 8.0+, пакет `ru.kipin.natal`, versionCode 100.

- Натальная карта, 10 разделов интерпретации, сохранённые карты и PDF без интернета.
- Исторические часовые пояса IANA, ручные UTC/DST для спорных случаев.
- Исправлены истинный узел, средняя Лилит, скорости и ретроградность; южный Vertex и заполярный ASC.
- Для полярных широт явно используется система домов по целым знакам.
- 299 тестов, в том числе 247 карт с независимыми эталонами Swiss Ephemeris; мобильная проверка офлайн-PDF пройдена.

Хирон остаётся двухтельным приближением, Селена — условной моделью (≈). Полная точность и ограничения: [ACCURACY-2026-10-18.md](https://github.com/kipingame-cell/natal-chart/blob/main/docs/ACCURACY-2026-10-18.md).

Контрольная сумма подписанного APK — в файле SHA256SUMS. Физический Android здесь не тестировался; проверены мобильный Chromium, содержимое, подпись v2/v3 и выравнивание APK.
