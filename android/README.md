# Натальная карта для Android

Android 8.0+, пакет `ru.kipin.natal`, версия 1.0.0 (100). Все расчёты, встроенные города, сохранённые карты и PDF работают без интернета. В этой офлайн-сборке онлайн-поиск городов скрыт; можно вводить координаты вручную. Исторические часовые пояса зависят от базы IANA системного WebView/ICU; ручной UTC доступен.

Сборка: `python android/build.py --sdk-root /path/to/sdk` (Android SDK build-tools 35, platform 35, Java 17+). Результат в `android/dist/`. Скрипт проверяет подпись и выравнивание APK.

Приватные ключи в `android/signing/` не коммитить и не публиковать. Для обновлений требуется та же подпись. Резервная копия создаётся отдельно в `android/dist/Natal-Chart-signing-backup.zip`.
